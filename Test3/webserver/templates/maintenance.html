SD Card Backup & Restore

Use this when replacing the SD card on site. Backup downloads all device credentials and configuration. Restore uploads the backup to the new SD card.

Step 1 — Download Backup (OLD SD Card)

Downloads all device DB files and encryption keys as a single .tar.gz file. Save this file on your phone before swapping the SD card.

Step 2 — Restore Backup (NEW SD Card)

After flashing and booting the new SD card, connect to its WiFi, open this page, select the backup file you downloaded, and tap Restore.
